Connecter QGIS
à un assistant IA via MCP

Relier l'assistant Claude Desktop à QGIS pour lui demander, en français, de charger une couche, lancer un traitement ou produire une carte. Le lien passe par un « serveur MCP » gratuit et open source, qu'on installe une fois sur le poste.

  • Environ 30 minutes la première fois
  • Gratuit et open source
  • Windows 10 et 11, QGIS 3.x

Le principe

Quatre pièces qui se parlent

Vous

Une demande en français

« Charge la couche des PAV et colore-les par commune. »

Claude Desktop

L'assistant

Comprend la demande et choisit les actions à faire dans QGIS.

Serveur MCP

L'interprète

Petit programme Python lancé par Claude Desktop sur le poste.

Plugin QGIS MCP

L'oreille dans QGIS

Reçoit les ordres et les exécute dans le projet ouvert.

MCP, c'est quoi ? Le Model Context Protocol est un standard qui permet à un assistant IA d'utiliser des logiciels installés sur l'ordinateur, un peu comme une prise universelle. Ici, il donne à Claude une « boîte à outils QGIS ».

Où vont les données ? QGIS et les fichiers restent sur le poste. Mais tout ce que Claude lit pour répondre (noms de couches, attributs consultés, résultats) part vers les serveurs d'Anthropic, l'éditeur de Claude. Voir les mises en garde.

L'outil utilisé est qgis_mcp, un projet communautaire publié sur GitHub. Il n'est édité ni par QGIS ni par Anthropic. Des guides payants circulent pour l'installer : ils ne sont pas nécessaires, tout est décrit ici.

Installer

Une seule fois par poste · à faire valider par le service informatique sur un poste professionnel

  1. Installer Claude Desktop

    Télécharger l'application Windows sur le site d'Anthropic, l'installer, puis se connecter avec un compte Claude.

    Bon à savoir : la version web de Claude (navigateur) ne peut pas piloter QGIS. Il faut l'application installée.

    claude.ai/download nouvel onglet

  2. Installer uv

    uv est un petit gestionnaire Python : il installera la bonne version de Python et les bibliothèques du serveur, sans toucher au reste du poste.

    Ouvrir PowerShell (touche Windows, taper powershell, Entrée) et coller la première commande. Puis fermer et rouvrir PowerShell et vérifier avec la seconde.

    Alternative : winget install --id=astral-sh.uv -e fonctionne aussi.

    PowerShell · installation
    PS C:\Users\vous> powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
    PowerShell · vérification
    PS C:\Users\vous> uv --version
uv 0.x.x

  3. Installer Python 3.12 via uv

    Le serveur demande Python 3.12. On l'installe à la main maintenant, plutôt que de laisser Claude Desktop le faire au premier lancement.

    Pourquoi ? Claude Desktop lance parfois le serveur plusieurs fois en même temps. Les téléchargements se gênent et l'installation de Python reste à moitié faite (erreur « Missing expected target directory »).

    PowerShell
    PS C:\Users\vous> uv python install 3.12
Installed Python 3.12.x

  4. Télécharger le projet qgis_mcp

    Sur la page GitHub du projet, cliquer sur le bouton vert Code, puis Download ZIP. Pas besoin de compte GitHub.

    Dézipper dans un dossier simple, sans espaces ni accents, par exemple C:\outils\qgis_mcp.

    Attention : le ZIP crée souvent un dossier qgis_mcp-main. Le renommer en qgis_mcp évite de devoir adapter les chemins plus loin.

    github.com/jjsantos01/qgis_mcp nouvel onglet

  5. Copier le plugin dans QGIS

    Dans QGIS : Préférences → Profils utilisateurs → Ouvrir le dossier du profil actif, puis aller dans python\plugins.

    Y copier uniquement le dossier qgis_mcp_plugin qui se trouve dans le projet dézippé. Pas le dossier entier du projet.

    Contrôle : en ouvrant plugins\qgis_mcp_plugin, on doit voir directement metadata.txt et __init__.py. Sinon QGIS affichera « Cette extension est corrompue ».

  6. Activer le plugin

    Fermer et rouvrir QGIS. Dans Extensions → Installer/Gérer les extensions, onglet Installées, cocher QGIS MCP.

    Le plugin n'est pas dans le dépôt officiel des extensions QGIS : il n'apparaît que parce qu'on l'a copié à la main à l'étape précédente.

  7. Préparer le serveur

    Cette commande télécharge les bibliothèques du serveur une bonne fois pour toutes. Adapter le chemin si le projet est ailleurs.

    Si la fenêtre semble bloquée sans message d'erreur, c'est bon signe : le serveur attend Claude. Faire Ctrl + C pour l'arrêter.

    PowerShell
    PS C:\Users\vous> uv --directory C:\outils\qgis_mcp\src\qgis_mcp run qgis_mcp_server.py
(curseur qui clignote : normal, faire Ctrl + C)

Configurer Claude Desktop

Lui indiquer comment lancer le serveur

  1. Ouvrir le fichier de configuration

    Dans Claude Desktop : Paramètres → Développeur → Modifier la configuration. L'explorateur s'ouvre sur le fichier claude_desktop_config.json. L'ouvrir avec le Bloc-notes.

    Autre accès : taper %APPDATA%\Claude dans la barre d'adresse de l'explorateur.

  2. Ajouter le serveur QGIS

    Si le fichier est vide ou ne contient que {} : tout remplacer par le bloc ci-contre.

    S'il contient déjà des réglages : ne rien effacer. Coller les lignes "mcpServers": { … }, juste après la première accolade {, avec une virgule à la fin pour les séparer du reste.

    Deux pièges : dans ce fichier, chaque \ d'un chemin Windows s'écrit \\. Et le chemin doit mener au dossier qui contient qgis_mcp_server.py.

    claude_desktop_config.json
    {
  "mcpServers": {
    "qgis": {
      "command": "uv",
      "args": [
        "--directory",
        "C:\\outils\\qgis_mcp\\src\\qgis_mcp",
        "run",
        "qgis_mcp_server.py"
      ]
    }
  }
}
    Fichier déjà rempli : où insérer
    {
  "mcpServers": { … le bloc qgis … },
  "preferences": { … réglages existants, inchangés … }
}

  3. Redémarrer Claude Desktop complètement

    Fermer la fenêtre ne suffit pas : faire clic droit sur l'icône Claude près de l'horloge, puis Quitter. Relancer ensuite l'application.

    Important : modifier le fichier pendant que Claude Desktop tourne peut faire perdre les changements, l'application réécrit ce fichier elle-même.

Utiliser

À chaque séance de travail

  1. Démarrer le serveur dans QGIS

    Ouvrir le projet QGIS, puis Extensions → QGIS MCP → QGIS MCP. Dans le panneau qui s'ouvre, cliquer sur Start Server.

    Toujours dans cet ordre : QGIS d'abord, Claude ensuite.

  2. Vérifier que Claude voit QGIS

    Dans une nouvelle conversation, cliquer sur le bouton + (ou l'icône des outils) dans la zone de saisie. qgis doit apparaître dans la liste, activé.

    S'il est absent, Claude Desktop n'a pas réussi à lancer le serveur : voir En cas de souci.

  3. Faire le test du « ping »

    Écrire simplement : « Fais un ping sur QGIS pour vérifier la connexion. »

    Claude demande l'autorisation d'utiliser l'outil. Cliquer sur Autoriser. S'il répond que QGIS a répondu, tout fonctionne.

Exemples de demandes

  • « Charge la couche C:\…\PAV.gpkg et zoome dessus. »Chargement de données
  • « Liste les couches du projet avec leur nombre d'entités et leur système de coordonnées. »Inventaire d'un projet reçu
  • « Compte les PAV par commune et donne-moi le résultat sous forme de tableau. »Statistiques simples
  • « Crée un tampon de 200 m autour des PAV et enregistre-le en GeoPackage. »Traitements
  • « Colore les PAV par type de flux, avec une légende claire. »Mise en forme
  • « Exporte la vue actuelle en PNG dans C:\…\cartes\pav.png. »Production de carte

Réflexe : ouvrir la table attributaire ou la couche produite pour vérifier le résultat, comme on le ferait pour le travail d'un stagiaire.

Intérêts et limites

Pour savoir quand ça vaut le coup

Ce que ça permet

  • Charger, ranger, styler des couches vecteur et raster.
  • Lancer les traitements de la boîte à outils QGIS (tampons, intersections, jointures…).
  • Interroger un projet : couches, champs, entités.
  • Exporter une carte en image, enregistrer le projet.
  • Exécuter du code Python dans QGIS pour tout le reste.

Avantages

  • Accessible sans connaître PyQGIS ni les menus avancés.
  • Gain de temps sur les tâches répétitives ou fastidieuses.
  • Pédagogique : on peut demander à Claude d'expliquer ce qu'il fait.
  • Données locales : les fichiers ne sont pas envoyés en bloc.
  • Gratuit côté outil, et réversible : on désactive le plugin.

Inconvénients

  • Installation technique, à refaire sur chaque poste.
  • Projet communautaire, sans support ni garantie de suivi.
  • Erreurs possibles : l'IA peut se tromper de champ, de projection, de couche.
  • Moins efficace que QGIS en direct pour les gestes simples.
  • Compte Claude requis, avec des limites d'usage selon l'abonnement.

Mises en garde

À lire avant toute utilisation sur des données de la collectivité

Claude peut exécuter du code sur le poste L'outil « exécuter du code » laisse Claude lancer n'importe quel script Python dans QGIS, avec les mêmes droits que vous : lire, modifier ou supprimer des fichiers.

Garder l'autorisation demandée à chaque action, lire ce qui est proposé, et travailler sur des copies des données.

Confidentialité et RGPD Ce que Claude consulte pour répondre (attributs, extraits de tables, chemins de fichiers) est envoyé aux serveurs d'Anthropic, aux États-Unis.

Ne pas l'utiliser sur des données personnelles (fichiers d'usagers, redevance, adresses nominatives) ni sur des données sous licence restreinte, comme les fichiers fonciers. En cas de doute, demander au DPO.

Validation par le service informatique L'installation ajoute des logiciels (uv, Python, plugin non officiel) et ouvre une connexion locale entre deux applications.

Sur un poste professionnel, faire valider la démarche avant de l'installer.

Fiabilité des résultats Claude peut se tromper avec assurance : mauvais champ, mauvaise unité, filtre oublié.

Tout résultat destiné à un rapport, un élu ou un marché doit être vérifié à la main.

Outil communautaire qgis_mcp est maintenu par un particulier et n'a été testé que sur certaines versions de QGIS. Une mise à jour de QGIS ou de Claude peut le casser.

Ne pas en faire une brique indispensable d'un processus métier.

Arrêter le serveur après usage Tant que Start Server est actif, QGIS accepte des ordres venant du poste.

Cliquer sur Stop Server (ou fermer QGIS) en fin de séance.

En cas de souci

Les messages rencontrés lors de l'installation

QGIS : « Cette extension est corrompue · Fichier de métadonnées manquant »Le mauvais dossier a été copié (souvent le projet entier, nommé qgis_mcp). Le supprimer de python\plugins et copier à la place qgis_mcp_plugin, qui contient metadata.txt.
Journal Claude : « Missing expected target directory for Python minor version link »Installation de Python interrompue. Quitter Claude Desktop, lancer uv python uninstall 3.12 puis uv python install 3.12, et refaire l'étape « Préparer le serveur ».
« qgis » n'apparaît pas dans les outils de ClaudeErreur dans le fichier de configuration (virgule manquante, \ non doublés) ou chemin faux. Les journaux sont dans %APPDATA%\Claude\logs, fichier mcp-server-qgis.log.
« uv n'est pas reconnu… » ou serveur qui ne démarre pasRouvrir PowerShell après l'installation d'uv. Si Claude ne le trouve toujours pas, taper Get-Command uv et remplacer "uv" par le chemin complet affiché, en doublant les \.
Claude répond que la connexion à QGIS est refuséeLe serveur n'est pas démarré dans QGIS. Cliquer sur Start Server, puis redemander.
Les modifications du fichier de configuration disparaissentClaude Desktop était ouvert pendant la modification. Le quitter complètement, refaire la modification, puis le relancer.
