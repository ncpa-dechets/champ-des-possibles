Une API, c’est quoi ?

Une adresse web qui renvoie des données brutes au lieu d’une page à lire. On écrit la question dans l’adresse, le serveur répond avec les données. Essayez : cette adresse demande les informations de Cabourg à l’API Géo.

geo.api.gouv.fr/communes?nom=Cabourg&fields=nom,code,population

La réponse arrive en JSON : du texte structuré, lisible par un programme. Firefox l’affiche joliment ; Excel et QGIS savent le lire.

Cinq types de ressources

APIInterrogation à la demande, réponse en JSON. Idéal pour un outil ou une mise à jour automatique.
API statistiqueIndicateurs et séries déjà calculés, filtrables par territoire et par année.
Flux SIGCouche cartographique (WMS, WMTS, WFS) à ajouter directement dans QGIS.
TéléchargementFichier complet (CSV, GeoPackage…). Souvent plus simple qu’une API pour une analyse ponctuelle ou de gros volumes.
CataloguePortail qui recense d’autres sources.

Quatre niveaux d’accès

LibreOn interroge directement, sans compte.
Inscription gratuiteOn crée un compte et on reçoit une clé (ou jeton) à joindre à chaque requête.
En partie restreintUne partie est ouverte ; le reste demande une habilitation ou un abonnement.
Sur habilitationRéservé aux administrations, après une demande justifiant l’usage.

Les exploiter sans être développeur

  • Excel : Données › À partir du web, coller l’adresse de l’API. Power Query transforme le JSON en tableau actualisable d’un clic.
  • QGIS : les flux SIG s’ajoutent comme une couche ; les GeoPackage s’ouvrent par glisser-déposer.
  • Python ou page HTML : pour automatiser, croiser plusieurs sources ou construire un outil.

Croiser les sources

Deux sources se relient grâce à un identifiant commun : le code INSEE de la commune, le SIREN de l’EPCI ou de l’entreprise, le SIRET de l’établissement, la référence cadastrale de la parcelle, ou l’identifiant BAN de l’adresse. Chaque fiche indique les identifiants disponibles.

Points de vigilance

  • Quotas : la plupart limitent le nombre de requêtes. Pour de gros volumes, préférer le fichier complet.
  • Pérennité : les adresses et les versions changent. L’API Adresse est passée de data.gouv.fr à l’IGN en 2025 ; Géorisques a introduit une version 2 avec jeton ; les anciens fichiers FINESS ne sont plus mis à jour depuis juillet 2026.
  • Licence : la Licence Ouverte impose de citer la source ; l’ODbL (OpenStreetMap, Atmo) impose en plus de repartager les bases dérivées sous la même licence.
  • Décalage : une donnée « à jour » peut avoir un ou deux ans de retard (recensement, enquêtes).
  • Données personnelles : croiser des sources ouvertes peut recréer des données sensibles ; le RGPD s’applique aux traitements qu’on en fait.
