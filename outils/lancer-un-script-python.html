Lancer un outil
écrit en Python

Plusieurs outils du catalogue sont des scripts Python (fichiers .py). On installe Python une seule fois sur le poste, puis deux commandes suffisent pour lancer chaque outil.

  • Une dizaine de minutes la première fois
  • Sans droits d'administrateur
  • Commandes à copier-coller

Installer Python

Une seule fois par poste

  1. Télécharger l'installateur

    Sur le site officiel, sous la dernière version Stable Release, cliquer sur Windows installer (64-bit).

    python.org/downloads/windows nouvel onglet

  2. Cocher la bonne case

    En bas de la première fenêtre, cocher Add python.exe to PATH. C'est l'étape qui compte : sans elle, la commande python ne sera pas reconnue.

    Sans droits d'administrateur, décocher Use admin privileges…, puis cliquer sur Install Now.

  3. Vérifier l'installation

    Ouvrir l'invite de commandes : touches Windows + R, taper cmd, puis Entrée. Coller la commande ci-contre et valider.

    Un numéro de version s'affiche : Python est prêt.

    Invite de commandes
    C:\Users\vous>python --version
Python 3.14.0

Lancer un script

Pour chaque nouvel outil récupéré

  1. Ouvrir l'invite de commandes dans le dossier du script

    Ranger le fichier .py dans un dossier, par exemple Documents\Outils, et l'ouvrir dans l'explorateur.

    Clic droit dans une zone vide du dossier, puis Ouvrir dans le Terminal. La fenêtre s'ouvre directement au bon endroit et accepte les mêmes commandes.

    Sous Windows 10 : Maj + clic droit, puis Ouvrir la fenêtre PowerShell ici.

    Autre méthode : cliquer dans la barre d'adresse du dossier, taper cmd, puis Entrée.

  2. Installer les bibliothèques

    Une seule fois par outil. La liste figure en tête du script, à la ligne Dépendances (exemple ci-contre : le comparateur des frais de personnel).

    Fichier requirements.txt fourni ? Utiliser plutôt la seconde commande.

    Liste indiquée dans le script
    …\Documents\Outils>python -m pip install requests pandas openpyxl matplotlib
    Avec un fichier requirements.txt
    …\Documents\Outils>python -m pip install -r requirements.txt

  3. Lancer l'outil

    Taper python suivi du nom du fichier. Les fois suivantes, seule cette commande est nécessaire.

    Plus rapide : taper python et une espace, puis glisser le fichier .py dans la fenêtre : son chemin s'écrit tout seul.

    Remplacer par le nom du script
    …\Documents\Outils>python comparateur_rh_ofgl.py

En cas de souci

Les messages les plus fréquents

« python n'est pas reconnu… » ou le Microsoft Store s'ouvreLa case Add python.exe to PATH n'a pas été cochée. Relancer l'installateur, la cocher, puis rouvrir l'invite de commandes. En attendant, py remplace souvent python.
« ModuleNotFoundError: No module named… »Une bibliothèque manque : refaire l'étape d'installation des bibliothèques, ou installer celle dont le nom est cité.
Erreur de connexion pendant l'installation des bibliothèquesLe réseau de la collectivité bloque probablement le téléchargement : contacter le service informatique.
La fenêtre se ferme aussitôtLancer l'outil depuis l'invite de commandes plutôt qu'en double-cliquant : le message d'erreur reste alors affiché.
